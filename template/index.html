Quotation page template. Every insurance product page (Type "Quotation" in content/PAGE_CONTENT.md) is built from this page. The blocks always come in this order:

  1. Hero: breadcrumb, H1, subheading, hero photo
  2. Quote options (top CTA): the same quote method(s) as the item on Get a free quote
  3. Information: why choose us, coverage, eligibility, prices, testimonials, FAQs (in that order)
  4. Quote options (bottom CTA): a repeat of block 2, then the standard contact block
  5. Related links: sibling products, category overview, forms, articles
  • Required blocks are on every page. Optional blocks are used only when PAGE_CONTENT.md has content for them. If there is no content, leave the whole block out (and its entry in the "On this page" list). Never ship an empty heading or "coming soon".
  • {Highlighted text} is a placeholder. Replace it with the text from PAGE_CONTENT.md, keeping the live wording where the brief says so.
  • The quote option variants and the handling rules are at the bottom of this page.
  • Use the button at the bottom right to hide these notes and see the page as a visitor would.

How to build them:
  • One item per sub-page. Button = title, with date and author as small text. Body = the full text from the Appendix of PAGE_CONTENT.md (headings inside drop to <h4>; Scripture verse as a blockquote). Media the browser cannot play (.pps, .wmv) is left out and flagged.
  • id = the old file name without the extension (id="dario_08_05_22"). js/accordions.js opens any item whose id is in the URL, so the old page can redirect to jds-meditations.htm#dario_08_05_22 and links from elsewhere keep working. Try it: open "I Had Forgotten".
  • Up to ~12 items: one flat accordion. More: nested accordions grouped by year (or topic), newest first, with a count badge, same nesting as the quote page. One panel open per level (data-bs-parent).
  • Long structured sub-pages (auto reform Q&A with 21 questions, the self-assessment checklist): the item body holds its own nested accordion or checklist.
  • The parent page gets one heading for the set, a 1–2 line intro, and its own "On this page" link. Remove the old sub-page from the build list in PAGE_CONTENT.md and note the redirect.

Appendix B: handling rules

Element / situationHow to handle it
File, <title>, metaKeep the live file name (e.g. jds-packages_tool_and_die.htm) so old links work. Use the brief's Suggested <title>, ending "| JD Smith Insurance". Use the Suggested meta; if there is none, write one of 150–160 characters. Fix "Untitled Document" and copied titles. Include the gtag block; never noindex.
Header & footer<site-header> and <site-footer> only. Never paste nav or footer markup. Never add the blue top banner.
Quote methodsCopied from jds-get_a_quote.htm. Forms and PDFs link to https://jdsmithinsurance.com/.... A page that "has no tool" (Home: by phone only) never promises one.
Phone numbersAlways tel:. Extension = comma pause: tel:+19057647868,245. Show it as "905-764-7868 ext. 245". Unconfirmed direct lines (STAKEHOLDER_NOTES 2.5) are not used.
Conflicting factsExtensions, prices, broker counts: use the value on the quote page / site map, and log the conflict in STAKEHOLDER_NOTES.txt. Never pick a value silently.
Images of textTitle gifs, "Quote me" buttons, "Amazing rates" banners: never used. Replace with a real heading or button.
PhotosHero: suggested replacement (decorative, alt=""). In-content photos: real alt. Staff, office, community and event photos: keep the real JD Smith photo even if small. No stock photos of "staff".
CAPS & shoutingRewrite to sentence case; keep emphasis with <strong>. Keep the live meaning and figures exactly.
Dated contentStats or news with a year (2016, 2022): add the year to the caption and flag it. News stories move to News & humour.
Missing contentLeave the block out completely, along with its "On this page" link. Never "coming soon" or an empty heading. Required blocks (hero, both CTAs, contact, related) always appear.
External linksNew tab, rel="noopener", bi-box-arrow-up-right icon, source named in the text. Strip tracking parameters (utm_*, sid=) where the link still works without them.
Sub-pages & articlesNo separate page. Each becomes an accordion item on the parent (see 3h), id = old file name, grouped by year when there are more than ~12. The old URL redirects to parent.htm#id; js/accordions.js opens it.
Overview + quotation pagesjds-life_health.htm is both: use this template, and put the product cards of the category (overview layout) right after Information, before the bottom CTA.
After building a pageAdd it to the "Purpose of each page" list in CLAUDE.md. Check it at phone width, with the accordions, and that every tel: and PDF link opens.
